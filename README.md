# Nikoh to'yi taklifnomasi / Свадебное приглашение

## Havolalar / Ссылки
- O'zbekcha: `https://SAYT/uz/`
- Русский: `https://SAYT/ru/`
- `https://SAYT/` — brauzer tiliga qarab avtomatik yo'naltiradi.

## Ma'lumotlarni o'zgartirish / Изменение данных
Hammasi bitta faylda: `assets/js/config.js` — ismlar, sana/vaqt, to'yxona, manzil, koordinatalar,
fon musiqasi.

Matnlar `uz/index.html` va `ru/index.html` ichida.

Koordinatalarni olish: Google Maps'da to'yxonani bosing → pastda chiqqan `41.31…, 69.24…` raqamlarini nusxalang.

Musiqa: mp3 faylni `assets/audio/music.mp3` ga qo'ying va config'da `music: "../assets/audio/music.mp3"` deb yozing.

## Joylashtirish / Публикация
Statik sayt — GitHub Pages, Netlify, Vercel yoki istalgan hostingga papkani shundayicha yuklang.

Lokal ko'rish: `npx http-server -p 8080 .` → http://localhost:8080
